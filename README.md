# ИП Болдушевский Денис Викторович — плитка, бетон, ливневка, газоны. Минск

Шесть страниц: index, uslugi, raboty, o-brigade, kontakty, politika.

Интерактив: рисунки укладки (перевязка, дорожка, сетка, диагональ). SVG строится в build.py по точной сетке плитки 200 × 100 мм, шов 2 мм. Проверено растеризацией: доля фона в схеме около 7 процентов, то есть только швы, без дыр в раскладке.

Критический CSS встроен в <style> ДО ссылки на assets/css/style.v1.css.

## Перед запуском
1. УНП в подвал и политику.
2. Реальные фото объектов вместо сгенерированных.
3. В брифе два разных значения опыта: «больше 10 лет» и «опыт 27 лет». На сайте стоит 27 лет, нужно подтвердить.
4. Подтвердить формулировки: работа зимой, выезд за пределы Минска, что входит в гарантию 5 лет.
5. Ёлочку в схеме не рисую (нет точной раскладки), в тексте она упомянута как вариант.
